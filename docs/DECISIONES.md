- D-006: portabilidad Windows primero, UI con CSS local y prueba offline.
- D-007: reutilizar motor FreeShow/JA en etapa de integración, no construir otro reproductor de video/YouTube/Biblia. E1 es infraestructura experimental, no equivalencia funcional.
- D-008: conservar proyectos, escenas, perfiles y acciones como conceptos distintos.
